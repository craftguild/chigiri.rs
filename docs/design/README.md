# Design authorities

Read [implementation rules](../implementation-rules.md),
[architecture](../architecture.md), [implementation handoff](../implementation-handoff.md)
and [specification conformance](../spec-conformance.md), then the relevant
[ADRs](../adr/). Keep these stable authority paths when linking from source or
checks. The [documentation index](../README.md) describes their current scope.

The implementation rules define measurement and ownership. Architecture defines
runtime and host responsibilities. The handoff identifies implementation
boundaries. Conformance maps required behavior to explicit tests and fixtures.
ADRs retain numbered decisions, statuses and supersession relationships.
Historical execution records are preserved privately and are not gate inputs.
