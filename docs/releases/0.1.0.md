# chigiri.rs 0.1.0

This initial release contains the `chigiri` CLI, Rust GraphQL libraries,
and editable Luau mock servers. Generated resolver contracts use ABI 8 and the
application-owned transport lifecycle described in the current design.

Build with Rust 1.95.0 and the fixed standards v0.6.1 engine. Follow the
[project README](../../README.md) for installation and the Mock quick start, and
[building and installation](../building.md) for platform prerequisites.

The [GitHub Release](https://github.com/craftguild/chigiri.rs/releases/tag/v0.1.0)
provides Linux x86_64 and macOS arm64 CLI binaries, SBOMs and checksums, alongside
the generated changes and source revision. Product support and remaining
qualification boundaries are described in the [support policy](../support-policy.md)
and [validation guide](../validation.md). Registry packages and formal performance
qualification are outside this release.
